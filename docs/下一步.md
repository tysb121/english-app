## 当前代码相对方向差在哪

应用已经具备：水平门、教练线程、认词→场景对话→考核、流式聊天、职场种子分档等。方向文档要求改成：

- 默认主词书改为 CEFR 入门/基础/进阶（职场短句变加餐）
- 本级未教词随机抽取 + 本地记账跳过
- 一天改为认词 → 造句 → 短对话，**去掉单独四题考核**
- 本级将尽时提示升级，确认后明天生效

以上都还没按方向文档改实现。

## 建议实现顺序（改代码时）

做完一项再做下一项。每项先 `flutter test`，不访问真 DeepSeek。

1. 选定并装入 CEFR 主词书（含中文与署名），水平枚举改为入门/基础/进阶；职场种子改为可选词书。
2. 选词改为「当前级未教随机 + 冻住」；升级提示与明天生效。
3. 一天线程改为认词 → 逐词造句 → 短对话；打卡三条件对齐；移除对四题考核的依赖。
4. 回写 [能力设计.md](能力设计.md) 与 [产品交互.md](产品交互.md)，删掉过时四题描述。
5. 安卓真机或模拟器走通一天闭环。

## 不要做

- 不为词表自建后端；词库装本机即可。
- 不让模型发明今日词表或自动改水平。
- 不把密钥、进度 JSON、构建产物写进 git。
- 不在这一轮做语音、账号、云同步。
