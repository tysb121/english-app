本文记录当晚产品讨论的结论。与 [目标.md](目标.md)、[能力设计.md](能力设计.md)、[产品交互.md](产品交互.md) 冲突时，**以本文为准**。能力设计与产品交互已按本文回写；代码主路径（CEFR、认词→造句→短对话、升级提示）已接线。

## 一句话

默认练习是 **CEFR 分级词 + 认词 → 造句 → 短对话**。约 70 条职场短句种子已 **整份删除**（不做加餐）。

## 已定

### 主词书与水平

- 默认主词书：CEFR 思路的分级词汇（先做 A1 / A2 / B1 够用即可）。
- 用户看到的名称：**入门 / 基础 / 进阶**（对应 A1 / A2 / B1）。
- 词条需要可靠中文释义；分级清楚比「词条特别全」更重要。
- 考试向词书（如初中/四六级合集）、KyleBing 一类：**可作加餐，不作默认**。
- 职场短句种子：已删除；不加餐入口。

### 每天词数与选词

- 默认每天 **5** 个新词；设置里仍可选 10 / 15 / 20。
- 从 **当前水平、尚未当过新词** 的池子里抽取；抽过的记入本地，下次当新词跳过。
- 抽法偏向「未教集合中的随机」，而不是写死固定顺序表感。
- 当天计划第一次生成后 **冻住**；改词数或改水平都从 **明天** 生效。
- 选词、复习日、打卡由 **本地** 决定。模型不发明今日词表，不改水平，不改复习日。

### 何时升级

- **不自动跳级**，模型也不改水平。
- 当本级「还未当过新词」的库存 **已经为 0**（全部教过）且存在下一档时，在「今天」或「我的」提示是否升到下一档。
- 用户确认后，从 **明天** 按新级抽词；今天计划不动。
- 也可在「我的」随时手动改水平（同样明天生效）。
- 升级后，未掌握词与错词仍按复习回来，不因升级丢进度。

### 一天练完长什么样

**聊天主线（2026-09-30 晚间定稿）**：同一条教练聊天即练习本身；取消认词→造句→短对话三段切换 UI。

1. 「今天」点进教练聊天；今日词本地冻住后交给模型（模型不得增删改词表或日期）。
2. 气泡旁词卡「懂了」= 旧认词（离线记账）；点过即见过。
3. 造句∪对话合并：教练引导用词；本地记「用过」——用户消息命中今日词，或点词 chip 填入输入框。
4. 弱提示 / 开口变为输入框上方 quick-reply；软纠错写在气泡里。
5. 短轮次上限约 6 轮（本地计数）；无跳过按钮。进度行如「还差：词× / 轮次×」。
6. 打卡三条件仍本地：全部新词「懂了」+ 每个新词「用过」≥1 + 轮次达标 → 本地收尾气泡「今天练完了」；模型不宣布打卡。中途退出可续练。

**取消**单独的四题考核。**中→英听写/默写**不在日环。错词仍可另练，不挡打卡。

完成后主按钮「回看今天」。**原则：聊天是皮，进度仍是本地日环。**

### 模型分工（不变的原则）

- 模型：造句批改、短对话与场景文案、讲解。
- 本地：选词、冻住计划、对错写入、复习间隔、打卡、笔记是否保存。
- 不把模型自由文本当成进度；结构化结果仍需本地校验。

### 不做（本轮仍成立）

- 自建后端、账号、云同步（词库体积小，装本机即可，不为词表建后端）。
- 语音输入与发音打分。
- 让模型自行判断用户水平并自动升档。
- 用模型每天凭空发明词表且不落本地账。
