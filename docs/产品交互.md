# 产品交互

日期：2026-09-30。本文定下一版整个应用怎么用：启动看见什么、底栏有几项、一天怎么做完、记录和设置放在哪。学习规则、打卡条件和模型分工仍以 [能力设计.md](能力设计.md) 为准。教练线程里的上下文压缩以 [聊天规划.md](聊天规划.md) 为准。

已装上手机的表单版仍写在 [界面.md](界面.md)。按本文改代码之前，手机上的界面不变。这一步只写文档。

`prototype/index.html` 证明了教练线程的手感：一条对话、底部输入、认词一次列出。它还不是一个应用。下面补上外壳。

## 这个应用做什么

上班间隙打开，做完今天这一小段就能离开。一段大约几分钟，关掉以后停在原地。一天只有一条练习，做完有记录。

教练线程是练习本身，不是旁边再开一个自由聊天。外壳负责让人知道今天做没做、以前做过什么、要改的偏好在哪里。

屏幕名称是「今日英语」。界面文字用中文，要练的词和句子用英文。浅底深字。纸色 `#FFF6F4EF`，墨色 `#1B1B1B`，主操作松绿 `#0E6B45`，错误暗红色 `#8E2F2F`。主按钮只用这一种绿。打卡不放烟花，不要求分享。

## 参考了什么

| 产品 | 值得留下的 | 不搬的 |
|---|---|---|
| 多邻国 | 打开就是今天要做的事；一天的进度看得见；练习从首页推进去，做完回到首页 | 联赛、商店、红心、宝石、连续天数动画、五六个底栏图标。2026 年它的底栏是学习路径、练习、联赛等，练习里还有纠错、单词、听说。我们没有这些内容 |
| 墨墨背单词、不背单词 | 首页一个主操作；每天新词数量在设置里；记录用日历看哪天学过；设置不和「开始学」抢同一层 | 账号、云同步、词书商店、遗忘曲线大图、签到压力。墨墨可以藏起底栏做沉浸复习，我们只在进入练习时藏起底栏 |
| Speak 一类 AI 口语应用 | 纠正发生在对话里，而不是另开一张评分表 | 语音、订阅、和正课拆开的 Free Talk。拆开之后聊天和今天的词没有关系，会变成一个玩具对话框 |

## 讨论过的结构

底栏数量：

- 两项（今天、我的）会把词表和记录都塞进「我的」。查一个词、看昨天学了什么，都要多点一层。
- 三项（今天、词、我的）把记录放进「我的」顶部。能做，但记录是这个应用证明「我在学」的地方，和密钥、每天词数不是一类事情。
- 五项会多出空图标。多邻国的联赛和商店在这里没有对应内容。
- 采用四项：今天、词、记录、我的。练习不占底栏。

启动落点：

- 每次都直接掉进线程，续练最快，但关掉之后再打开看不见今天完成没有，应用只剩一个对话框。
- 每次都先回首页，再点一次才续上。多一次点击，首页能回答「今天做没做」。
- 采用：正常启动落在「今天」。人是从练习里被系统杀掉的，再打开回到那条线程、停在那一句。人自己点关闭回到了今天，下次打开仍是今天。

自由聊天：

- 单独再做一个「随便聊聊」，和 Speak 的 Free Talk 一样，会和当天的词脱节。
- 采用：第一版只有今天这一条线程。做完之后可以回看，不能把它当成另一个聊天窗口继续空聊。

首页要不要把英文答案亮出来：

- 已装版本在今天页直接放英文和中文，认词还没做，答案已经在上面。
- 采用：还没认过的说法，今天页只显示中文。认过之后再显示英文，方便回忆今天学了什么。

认词错了能不能当天再判一次：

- 多邻国会让人把这一关重做到达标。
- 我们的规则是同一次出现只判一次，错的进明天的错词。产品上不再加一套补考。没到通过线时，线程里用一句话说明今天先不打卡、错的明天再出现。
- 考核不同。能力设计允许重做没过的题，线程里保留这个重做。

## 信息架构

```text
第一次打开
  选择水平 → 填写 DeepSeek 密钥 → 今天

之后打开
  今天
    └─ 教练线程（盖住底栏，关闭回到今天）
  词
    └─ 词卡
  记录
    └─ 某一天的只读详情
  我的
    └─ 练习偏好、连接、关于这台手机
```

四个根页面显示底栏。教练线程、词卡、某一天的详情盖住底栏。左上角关闭和系统返回都只离开当前页，不丢已经记下的进度。

## 启动

安装后第一次打开，不进今天，也不先要密钥。

第一屏是三张水平卡，每张一个名字和一句例子。点一张就记住，没有「下一步」教程，也不问称呼。

| 水平 | 卡上的例子 |
|---|---|
| 新手 | I'm running late. 要迟到了 |
| 简单工作对话 | Let's start the standup. 我们开始站会。 |
| 更长的表达 | Let's take this offline. 会下再说。 |

水平决定从哪一档说法开始，也决定教练句子有多短、中文有多少。新手从短句开始，例如 sounds good、let me check、running late、I'll get back to you，不从 standup、bandwidth 开始。简单工作对话用会议里的说法。更长的表达用 take this offline、stakeholder、alignment 这一档。每天新词数量仍默认 5。这一屏不需要网络。

第二屏是 DeepSeek 密钥。地址和模型名收在「高级」里，默认 `https://api.deepseek.com` 和 `deepseek-flash`。「测试连接」按下后变成「正在测试」，结果写在按钮下面：连通是松绿「已连通」，失败是暗红原因。连通之后主按钮变成「开始今天」。参考翻译的 TokenHub 密钥放在折叠里，不填也能开始。空密钥按「测试连接」显示「密钥无效」。

已经保存过非空密钥时，以后启动不再拦这一屏。连接可以稍后在「我的」里重测。

已保存的水平若是旧值「日常交流」，下一版按「新手」读。没改过、仍是「简单工作对话」的保持不变。

## 底栏

| 项 | 回答的问题 |
|---|---|
| 今天 | 现在该练什么，练到哪了 |
| 词 | 这个说法是什么，下一次什么时候出现 |
| 记录 | 哪些天做完了，那天学了什么 |
| 我的 | 每天练几个、什么水平、密钥是否还有效 |

「设置」不占底栏。密钥和偏好都在「我的」。

## 一天的闭环

这是一个人从安装到第二天能走完的路径。

1. 选择「新手」，填入 DeepSeek 密钥，测试为已连通，进入今天。
2. 今天显示日期、连续天数、三枚空心状态（认词、对话、考核），主按钮是「开始今天」。下面 5 行中文，不显示英文。
3. 点进去，底栏消失。线程一次列出这 5 句中文，请用户用英文回答。比对在本地完成，忽略大小写和首尾空格。教练标出对的，并给出错的那句英文。
4. 认词达到能力设计里的通过线后，线程写今天的场景。场景只向 DeepSeek 要一次。写的时候可以离开，回来仍是这一步。
5. 对方一句、用户一句。用户的话交给批改，线程里给出至多两处问题和一句改对的英文，然后下一句。
6. 对话走完，可以点「这个语法」看本地卡片。不点也能往下。卡片上的「再讲讲」才调用讲解。
7. 考核一次一题，共 4 题。少于 3 题通过时，线程提供重做没过的题，当天不打卡。不少于 3 题通过时，考核这枚点亮。
8. 若有到期错词，最多 3 条排在考核之后。错词不影响已经成立的考核，也不单独决定打卡。没有则跳过。
9. 三条打卡条件都成立时，本地把今天记为完成。线程给出最多 5 条笔记草稿，每条是「错法 → 改对的句子 → 一句中文原因」。保存或跳过都可以。跳过仍然算今天完成。这个草稿只自动出现一次。
10. 关闭回到今天。三枚实心，主按钮变成「回看今天」。记录里这一天是实心，点开能看到场景名、词和笔记。
11. 第二天打开仍是今天。新的 5 个说法，加上到了复习日的词。昨天没做完的复习会出现在新的一天里。昨天的计划不重抽。

中途关掉应用，再打开停在没做完的那一步。同一句已经判过的，再打开看到原来的结果，不再判第二次。

认词没到通过线：对话和考核仍可继续，今天不打卡。线程写明错的明天再出现。

## 今天

打开应用后的第一眼是这一页。

顶部一行：日期，连续天数。连续天数算到最近一个已打卡日。今天还没练完时，先保持到昨天的连续天数，不因为今天未完成就归零。中间断了一整天，连续天数从 0 再计。不提供连胜保护，也不做补签。

三枚状态：认词、对话、考核。完成的实心，未完成的空心。三枚都实心时，日期旁边显示「已完成」。

中间一个主按钮，文案按进度变：

| 状态 | 按钮 |
|---|---|
| 今天还没开始 | 开始今天 |
| 认词未做完 | 继续认词 |
| 认词已过，场景还在写 | 正在写今天的场景 |
| 对话未完 | 继续对话 |
| 对话已完，考核未完 | 继续考核 |
| 考核已过，还有到期错词 | 还有错词 |
| 今天已完成 | 回看今天 |

主按钮进入同一条教练线程，停在对应的那一步。今天页不再为认词、对话、考核、错词各放一个入口。

按钮下面是今天的说法。未认的只显示中文。认过的加上英文。有到期复习时加一行「复习 n」。有到期错词时加一行「错词 n，排在考核之后」。没有就不显示。

不在这一页放聊天记录，不放场景正文，不放第二套练习按钮。

## 教练线程

从今天推进来，占满屏幕，底栏隐藏。标题是「今日英语」。关闭回到今天。

底部是输入框和发送。中英文都能发。空白不发送。等待时发送位置显示进行中，不能连发。失败原因用暗红色写在最后一条下面，旁边是「重试」。重试不重复追加用户那条。

线程按上面的闭环往下走。模型负责场景、开放题批改和讲解。认词对错、复习日期、打卡和笔记是否保存由本地决定。模型不能宣布打卡，也不能改日期。

上下文变长之后的压缩按 [聊天规划.md](聊天规划.md) 做：屏幕上留全文，发给模型的是投影。检查点不画成用户气泡。

回看今天时，同一条线程只读。输入框收起。不重新批改，不移动复习日期。

对方英文句子在有 TokenHub 密钥时可以点「参考译文」。没填则不显示这个动作。场景里已经生成的中文仍在。

## 词

一张可滚动的列表。先是今天的说法，再是还没学到的种子词和自己加的词。

点一行进入词卡：英文、中文、词性、下一次什么时候出现。有例句且填了翻译密钥时，可以点参考译文。

列表顶部有「添加」。三个字段：英文、中文、词性。保存后停在这张新词卡上，并写明「从明天开始练」。今天的计划已经冻住，不能把新词插进今天。

自己加的词和种子词走同一套进度。还没用到的手动词，优先于种子词进入以后的新词名额。

## 记录

记录回答「我哪些天做完了」，不负责继续练习。没做完的今天从「今天」进去，不从记录进线程。

默认是当月月历。

- 实心：这一天已打卡。
- 空心：这一天打开过，计划已生成，但没打卡。
- 空白：没有计划。

月历上面三个数：连续天数、本月完成、累计完成。都由本地已打卡的日期算出。不画遗忘曲线，不画能力雷达，不放分享。

点某一天，进入只读详情：

- 日期，完成或未完成。
- 场景中文名。还没有场景就写「这天还没有场景」。
- 当天的说法，英文和中文。
- 保存过的笔记。没有就写「这天没有留下笔记」。

详情里不能改日期、不能删错词、不能重判。已有场景时可以「看当天的对话」，那是只读回看，发送不可用。

还没有任何一天时，月历位置写：「还没有记录。完成今天之后会出现在这里。」

## 我的

顶部三个数：累计完成、连续天数、在学的词。没有头像，没有昵称，没有登录。

练习偏好：

| 项 | 选项 |
|---|---|
| 每天新词 | 5、10、15、20 |
| 水平 | 新手、简单工作对话、更长的表达 |
| 目标 | 职场、日常、考试、都要 |
| 语气 | 简洁、朋友、老师 |

考试和「都要」只影响场景提示，不增加题型。页内一行说明：已经开始的今天不变，这些改动从明天生效。

连接：

- DeepSeek 密钥在最上面，带「测试连接」。进行中和结果的写法与启动第二屏相同。
- 地址和模型名收在「高级」。
- 参考翻译默认折起。展开后是 TokenHub 密钥，高级里是地址和模型名，默认 `https://tokenhub.tencentmaas.com/v1` 和 `hy-mt2-plus`。

关于这台手机：

- 学习记录只在这台手机上，卸载即删除。
- 第一版不提供导出、云同步和账号。
- 第一版不放提醒开关。系统通知以后若要做，再加一个时间，不先放一个不能用的开关。

更换密钥不删除学习记录，也不重抽已经冻住的今天。

## 离开、断网、空页面

练习做到一半，关闭或系统返回回到今天，进度留在那一步。进程被杀掉后再打开，回到线程里的那一句。

断网时，今天、词、记录、已写好的对话回看、认词和错词题面都能开。生成场景、开放题批改、讲解、参考译文、测试连接会失败，原因写在原处，不用整页错误。已经记下的对错不回滚。

词列表在还没有手动词时，仍然有种子词，不显示空白页。记录的空白文案见上面。我的在没有学习记录时，三个数都是 0。

## 这一版不做

语音和发音分、端侧翻译、iOS、自建后端、账号、云同步、导出、系统提醒、联赛和商店、连续天数动画、分享、和当天课程拆开的自由聊天、85 项能力矩阵、把大词库放进安装包。

## 和已装版本的差别

已装版本是底栏四项里的「设置」，今天页上多个练习入口，认词一屏一词，批改用半屏而不是线程。第一次打开只问密钥，不问水平。

下一版改成：底栏的第四项是「我的」；第一次打开先选水平再写密钥；今天只有一个主按钮；练习在一条线程里做完；记录用月历。学习规则不因为换了外壳而放宽。
