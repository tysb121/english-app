# 产品交互

日期：2026-09-30。本文定应用怎么用：启动、底栏、一天闭环、记录和设置。学习规则与打卡以 [能力设计.md](能力设计.md) 为准；产品定稿以 [产品方向-2026-09-30.md](产品方向-2026-09-30.md) 为准。教练线程上下文压缩以 [聊天规划.md](聊天规划.md) 为准。

更早的表单版见 [界面.md](界面.md)。`prototype/index.html` 只作手感参考。

## 这个应用做什么

上班间隙打开，做完今天这一小段就能离开。默认练习是 **CEFR 分级词 + 教练聊天主线**（懂了 / 用过 / 轮次）。一天一条练习，做完有记录。

教练线程是练习本身，不是旁边再开一个自由聊天。做完当天课后，线程可继续闲聊（仍是同一条线程），但不能当成与今日词脱节的第二个窗口。

屏幕名称是「今日英语」。界面文字用中文，要练的词和句子用英文。主操作松绿 / 青绿，错误暗红。打卡不放烟花，不要求分享。

## 启动

安装后第一次打开，先选水平，不问称呼，没有教程。

| 水平 | 对应 | 卡上的感觉 |
|---|---|---|
| 入门 | A1 | 最常用的短词与短句 |
| 基础 | A2 | 稍长一点的日常说法 |
| 进阶 | B1 | 更完整的表达 |

水平决定从哪一档 CEFR 词抽新词。每天新词默认 5。这一屏不需要网络。旧水平名（新手 / 简单工作对话 / 更长的表达 / 日常交流）读入时映射到入门 / 基础 / 进阶。

第二屏是 DeepSeek 密钥。「测试连接」结果写在按钮下；连通后可「开始今天」。也可「先看看，稍后再填密钥」。TokenHub 参考翻译密钥折起，不填也能开始。

已保存非空密钥时，以后启动不再拦密钥屏。水平已选过则不再拦水平屏。

## 底栏

| 项 | 回答的问题 |
|---|---|
| 今天 | 现在该练什么，练到哪了 |
| 词 | 这个说法是什么，下一次什么时候出现 |
| 记录 | 哪些天做完了，那天学了什么 |
| 我的 | 每天练几个、什么水平、密钥是否还有效 |

## 一天的闭环

1. 选择「入门」（或其它档），可选填密钥，进入今天。
2. 今天显示日期、连续天数、三枚状态（认词、造句、对话），主按钮「开始今天」。下面新词未认时可只显示中文。
3. 点进去，底栏消失。认词：一次一词，英文 + 中文 + 词性，点「认识了」；不默写。
4. 认词完成后，逐词造句：顶栏显示今天词与进度（如「今天词 / 造句 2/5」）；可点今天词填入输入框；弱提示起头方向；文案「写一句就能进下一步」。模型批改（至多两处问题 + 改对英文），批改后轻反馈并显示步内进度。
5. 造句做完后，生成（或沿用）今天场景，短对话：对方一句、你一句；首轮可有句子槽或 2–3 个可选开口；模型批改后轻反馈与步内进度。
6. 若有到期错词，最多 3 条可在对话后练。错词不单独决定打卡。中→英听写不在日环内。
7. 认词完成 + 造句做完 + 对话走完 → 本地打卡。可出笔记草稿；保存或跳过都行。打卡后若本地已有明天到期复习词，今天页一行预告。
8. 关闭回到今天。三枚实心，主按钮「回看今天」。
9. 第二天：按当前水平从未教池随机抽新词；昨天未完成的复习 / 错词按规则回来。昨天计划不重抽。

中途关掉再打开：停在未完成步骤；已判定的不重判。

**没有**单独的四题考核。

本级未教新词全部练完（库存为 0）时，「今天」或「我的」出现升级提示。确认后水平改为下一档，从明天抽词；今天不动。不自动跳级。

## 今天

顶部：日期、连续天数；完成后旁标「已完成」。

三枚状态：懂了、用过、轮次。完成实心，未完成空心。另有进度行「还差：词× / 轮次×」。

主按钮文案：

| 状态 | 按钮 |
|---|---|
| 今天还没开始 | 开始今天 |
| 已开始未打卡 | 继续练 |
| 已打卡且还有到期错词 | 还有错词 |
| 今天已完成 | 回看今天 |

按钮下是今天的说法：未认只中文，认过显示英文。有到期错词时可用文字按钮进入错词练习（不在打卡条件内）。

本级未教新词耗尽时显示升级卡片（升到下一档 / 暂不）。

## 教练线程

从今天推进来，占满屏幕。线程按闭环往下走。模型负责场景、造句/对话批改和讲解。认词是否点过、复习日期、打卡和笔记由本地决定。模型不能宣布打卡，也不能改水平或日期。文案避免考试感与「不能跳过」压迫感；造句强调写一句即可前进。

上下文压缩按 [聊天规划.md](聊天规划.md)。回看今天时只读，不重判。对方英文句在有 TokenHub 密钥时可点「参考译文」。

## 词

列表以已学 / 手动词为主（不全量铺开五千词）。点开词卡：英文、中文、词性、下次出现。顶部可添加英文 / 中文 / 词性；保存后写明从明天开始练。

## 记录

月历：实心已打卡、空心有计划未打卡、空白无计划。点某一天只读详情：场景名、说法、笔记。可只读回看当天对话。

## 我的

练习偏好：

| 项 | 选项 |
|---|---|
| 每天新词 | 5、10、15、20 |
| 水平 | 入门、基础、进阶 |
| 目标 | 职场、日常、考试、都要（影响场景提示，不加题型） |
| 语气 | 简洁、朋友、老师 |
| 思考强度 | 关 / 中 / 高（自由聊天 thinking） |

说明：今天计划已定，改水平与词数从明天生效。本级未教新词耗尽时同样显示升级卡片。

连接：DeepSeek 密钥 + 测试连接；TokenHub 折起。关于：学习记录只在本机，卸载即删；无导出 / 云同步 / 账号。

## 离开、断网、空页面

练习中途关闭回到今天，进度留在那一步。断网时认词、错词题面、已有回看可用；场景生成与批改失败，原因写在原处，已写入进度不回滚。

## 这一版不做

语音、端侧翻译、iOS、自建后端、账号云同步、导出、联赛商店、单独四题考核、职场短句种子、模型自动改水平。
