# 项目目标

> **2026-09-30 起**：默认练习路径与词表以 [产品方向-2026-09-30.md](产品方向-2026-09-30.md) 为准（CEFR 入门/基础/进阶；认词 → 造句 → 短对话；无单独四题考核；职场短句种子已删除）。细节合同见 [能力设计.md](能力设计.md)、[产品交互.md](产品交互.md)。
个人用的英语练习应用。每天学少量 CEFR 词，用造句和短对话把这些词用进去。进度、词表和密钥都留在这台设备上，不自建服务器。

灵感来自本机的 english-coach skill（`C:\Users\Administrator\.workbuddy\plugins\marketplaces\my-experts\plugins\english-coach`）。那个 skill 依附外部 agent，用脚本选词、用模型填教案。本应用把值得留下的规则做进应用本身，不把 skill 嵌进来，也不复制它的词库。

## 要达成的使用方式

打开应用就能练，不必先上完一节 25–70 分钟的课。一次片段大约 1–8 分钟，做完可以关掉。同一天的内容拆成多段，合在一起才算这一天练完。

一轮完整的一天是：

1. 本地从当前 CEFR 水平的未教池随机选出今天的新词，并带上到了复习日的旧词 / 错词。
2. 认词（离线）：看英文 + 中文 + 词性，点「认识了」；不默写、无正确率门槛。
3. 造句（需网络）：刚看过的词写一句，DeepSeek 结构化批改。
4. 短对话（需网络）：用今天的词做情景对话，模型批改。
5. 本地根据练习写入下一次出现的日期。
6. 认词完成 + 造句做完 + 对话走完后打卡。没打卡则下次打开停在未完成步骤。

模型不决定学哪些词，不改复习日期，也不直接改能力记录。

## 第一版做到这些算完成

能力范围见 [能力设计.md](能力设计.md)。验收在安卓手机上完成：安装应用，填入自己的 DeepSeek 密钥，走通认词、造句、短对话、错词和打卡。Chrome 只在需要时看布局，不承担模型调用。

- 第一次启动先选水平（入门 / 基础 / 进阶），再填 DeepSeek 密钥（可稍后）。密钥进系统安全存储。
- 默认主词书为 CEFR-J A1–B1 核心词（`cefr_core`），也可手动加词。两种词走同一套进度。
- 能看到今天要练的词，默认 5 个新词（设置可选 10 / 15 / 20）。
- 认词、错词日期、未完成进度在断网时仍可用。
- 在线时由 DeepSeek 返回场景、造句/对话批改。应用只接受约定好的 JSON，不把模型的自由文本当成进度。
- 练到一半退出，再打开仍停在同一个片段。
- 认词展示词表里的英文与中文。场景里的中文由 DeepSeek 和英文一起生成。整句参考译文调用 TokenHub 的 `hy-mt2-plus`，不参与判分。

## 学习规则

这些规则由本地代码执行。

- 每天新词数量默认 5，可改为 10、15 或 20；从当前水平未教池随机抽取并冻住。
- 打卡需要三件事同时成立：认词完成、造句做完、短对话走完。中→英听写不在日环内。
- 答错的词进入错词队列：明天再出现；之后答对则间隔改为 3 天，再答对改为 7 天；连续答对 3 次后移出队列。答错则回到明天。
- 没有进过错词队列的词，在第 2、4、8 天复习。错过的复习日下次打开时补上。
- 训练侧重只改变题目构成，不改变选词和日期算法。第一版先做「词加短对话」这一种练法。
- 语法讲解和场景提纲放在本地内容里。模型回答用户的追问，不改写这批内容。
- 能力记录从练习事件汇总。不提供让模型直接编辑这条记录的入口。
- 在有真实的语音评分之前，不记录发音成绩。

## 第一版不做

- 自建后端、账号和云同步。
- 把考试大词库当作默认主词书（可加餐，本轮未做入口）。职场短句种子已删除，不加回。
- 一次搬运 skill 里的全部场景、语法模块和 85 项能力矩阵界面。
- 语音输入、发音打分。
- 端侧腾讯 Hy-MT 或 llama.cpp。以后如果要做，只作为原生插件接入，不更换 Flutter。安装包不内置模型权重。1.25-bit 约 440MB 的文件依赖尚未进入主线 llama.cpp 的内核，不作为以后的默认文件；若做端侧翻译，优先常规 4-bit、约 1.1GB 的 GGUF。
- iOS。这台 Windows 电脑只安装到安卓手机。
- 把 Android Studio 当作开发依赖。模型相关功能直接安装到安卓手机上开发和验收。

## 运行与开发约束

- 客户端用 Flutter。课程引擎用普通 Dart 写成，界面和存储都调用它。
- 词表与进度分库保存。进度库记录学习事件；复习日期由这些事件算出。
- 手机用 HTTPS 直接调用 DeepSeek 和 TokenHub 上的 Hy-MT2，不自建服务器，也不需要自己的域名。浏览器打不开这些接口时，不改走代理，改为安装手机应用。Chrome 上的密钥存储和 SQLite 也与手机不同。
- 本机工具链：Flutter 3.47.5（`D:\flutter`），Android SDK 36（`D:\Android\sdk`，仅命令行工具），JDK 17（`D:\JAVA`）。`flutter doctor` 在 2026-09-29 无报错。国内依赖使用 `pub.flutter-io.cn` 与 `storage.flutter-io.cn`。
