# 老师 agent

本文是「今日英语」当前唯一的产品与实现合同。

这是手机端的英语老师 agent。课怎么排、难度、复习，以及这一步用选择、判断还是填空，都由模型根据工具读到的记录决定。没有固定课表，也没有写死的课次顺序。

程序只做四件事：工具循环、上下文压缩、工具读写、流式渲染。教学上的取舍不写进分支里。

实现和本文冲突时，先改本文，再改代码。

## 硬边界

这些由程序强制执行。只写在提示里不算数。

- 成绩只有工具成功才写下。校验失败、参数不合法、或调用没完成，都不改库。同一截里多个工具各自提交：失败的不写，也不回滚已经成功的。
- 学生的原句、点选的选项文字、填空内容，由程序从学生实际提交的内容抄入。模型参数里如果带了原文，一律丢掉，不能改写。
- 把一条学习项标成「会用」时，该条必须已经有一次作答同时满足：答案当时没有显示，而且判为通过（`pass` 为真，`revealed` 为假）。答错不算。否则 `set_plan` 失败，状态和复习时间都不变。
- 学生把正在练的英文遮住后再提交：这次作答的 `revealed` 记为假，原文仍是学生实际提交的内容。程序不因此写下对或错。英文当时还显示着，这个开关不把 `revealed` 改成假。只遮住中文也不改 `revealed`。
- 学生在卡片上点「不会」：用户消息和作答原文都是「这题我不会」，没有选项 id。这次 `revealed` 记为真。程序不因此写下对或错。「不会」不是选项，不占用 `choice` 的 2–4 项，也不占 `judge` 的 2 项。
- 旧课气泡不发给模型。模型要历史，只能调用查询工具，拿到的是结构化记录，不是旧对话。

## 教学偏好

下面只写进系统提示，程序不设门槛、不代模型改难度或复习时间：

- 同一类错误反复出现，先复习，不往前赶。
- 连续轻松，就加难度，并推迟复习。
- 连续吃力，就把这一步改短，并提前复习。
- 能点选的用卡片。要学生自己写整句时，让用户打字，不要塞进卡片。
- 对学生说的话只用中文。英文只写正在练的那一句。
- 读记录、调用工具和思考不要说出来。调用工具的那一截不要同时写给学生看的正文。
- 学生一提交句子或确认卡片，这一问先记下作答：没有学习项就先 `add_item`，下一截再用返回的 id 调用 `record_attempt`。这两步完成前不要出卡片，也不要先讲解。没记成功不要当成已经记下。
- 新词优先从学生当前水平里取。拿不准这个词在不在这一档，再查词库，不必每句都查。词库释义只作参考，不在词库里也可以教。
- 新词先单独认，再放进短句。句里出现还没练过的词，先把那个词拆出来。
- 点选只用来认。要标成「会用」，就让学生自己把句子写出来，而且当时答案没有显示。
- 学生点「不会」时，用中文讲这一项。不要把「这题我不会」当成某个选项，也不要据此标成「会用」。

## 工具循环

每一问都是流式请求。模型正文的增量画进气泡。工具参数不展示，工具 JSON 也不进气泡。

查询或写入执行完，把结果送回模型，再开下一截。这段时间状态行显示「在看记录」。正文一开始增量出现，状态行就让位。

`present_card` 的参数合法时，卡片升起，循环停住，等学生确认。不在未确认时再请求下一截。学生确认后，程序把确认写成一条用户消息，再开始新的一问。已有未确认卡片时，再出的卡直接失败，不升起第二张。

同一截里如果既有查询/写入，又有合法的 `present_card`：先执行查询和写入，再升起卡片并停止。同一截里的 `end_class` 不在这张卡确认前收课。

一问一答最多 4 截。有给学生看的正文，或有一张合法卡片，这一问就可以停，不必凑满 4 截。第 4 截里的查询和写入仍然执行。执行完如果还没有给学生看的正文，也没有合法卡片，就不再请求第 5 截，提示学生再发一次。已经成功的写入保留。

如果这一问有还没记下的学生提交，模型却停在正文上：程序不替它判断对错，也不改已经写出的正文。只要还没到 4 截，就再请求一截，塞入一条不显示的提示，只要求先 `add_item`（如果还没有这一条）再 `record_attempt`，并且这一截不要再写给学生看的话。记下之后，如果正文已经有了，就不再为了多说一句而继续请求。这一截仍然没记成功，成绩不写，已经写出的正文保留。这条提示不画在屏幕上，不算学生消息。

新的一节开始时，程序塞入一条不显示的提示，当作发给模型的第一条用户消息：

> 新的一节开始，学生还没说话。用工具读记录，不要把这一步说出来。然后只用中文跟他说第一句。

这条提示不画在屏幕上，不算学生消息，不计入下面的 12 条。

## 发给模型的上下文

屏幕留着本节全部消息。节内的检查点折叠不从屏幕上删字。

发给模型的只有两样：一段短系统提示，加上当前这一节的对话。短系统提示里包括老师身份、上一节的教学偏好，以及上一节的三行收课条（第一节没有收课条）。不附成绩册长文，不附旧课气泡。

收课条由程序在收课时本地写成，正好三行，只根据这一节已经写入的记录来写（练了什么、对错、下次何时到期）。不调用模型做摘要，不摘录对话原文。

本节发给模型的正文超过约 12000 字时，沿用现有投影：预算约 12000 字，最近 4 个用户回合保留原文，更早的折成检查点。检查点以 `untilMessageId` 标明截到哪一条，另加检查点正文；它不是气泡。检查点只在本节内使用，不带进下一节。

卡片在线程里是两条普通消息：老师的题面，以及学生确认的文字。不保留工具 JSON。题面可以包含题干；选择和判断可以带选项文字，但不得写下正确答案。

## 工具

模型用工具读记录、写记录。查询不写成绩。写入类工具成功才落库。

| 工具 | 作用 | 字段 |
| --- | --- | --- |
| `get_learner` | 读学生事实和「我的」里已选的水平、目标 | 无。返回名字、工作、自由目标，以及水平（入门 / 基础 / 进阶）和设置里的目标（职场 / 日常 / 考试 / 都要） |
| `lookup_words` | 按中文或英文查本机词库 | `query`。可选 `band`（`a1` / `a2` / `b1`，或入门 / 基础 / 进阶），缺省为学生当前水平。可选 `limit`，最多 8 条 |
| `get_due_items` | 读到期且还不是「会用」的学习项 | 无。程序过滤：`due_at <= now`，且状态不是「会用」 |
| `get_recent_attempts` | 读最近作答 | 无。只返回作答记录本身，条数由程序限制 |
| `get_error_patterns` | 按错误类型看还没稳住的模式 | 无。数据来自作答记录，不返回旧课对话 |
| `add_item` | 新增一条学习项 | `prompt_cn`、`target_en`、`difficulty`（整数 1–5）、`reason` |
| `set_plan` | 改一条的状态和复习时间 | 哪一条（此前工具返回的 id）、`status`、`due_at` |
| `record_attempt` | 记下一次判定 | 哪一条、对错、错误类型、`corrected_en`、`revealed`。原文由程序填 |
| `note_fact` | 记下学生事实 | 一次一项：`key`（`name` / `job` / `goal`，或中文「名字」「工作」「目标」）、`value`。其它 key 失败且不写。没提到的事实保持原值 |
| `end_class` | 请求收课 | 无。不写成绩 |
| `present_card` | 升起确认卡并停住 | `kind`、`prompt`、`options` |

`lookup_words` 只读词库，不写学习项，也不写作答。每条有英文、中文、词性和等级。查不到，或释义明显不准，都不阻止后面的 `add_item`。程序不因为词不在当前水平就拒绝一句新句子，也不禁止再出一张选择题。模型可以不调用这个工具。

`status` 只接受：没练过、不稳、会用。

`due_at` 是可与当前时间比较的绝对时间，不用「明天」这类相对说法落库。`add_item` 新建的条目状态为「没练过」，`due_at` 为空，因此不会出现在 `get_due_items` 里，直到某次 `set_plan` 成功写上时间。

`revealed` 表示作答前答案有没有显示，以模型传入的值为准，程序不改写。卡片界面本身不放正确答案。

`record_attempt` 答对时可以不写错误类型。写了、但不在下面这张表里的，记成「其它」，这次作答仍然保存。空着就空着：

缺冠词、语序、时态、拼写、用错词、漏主语、夹了中文、其它。

`present_card` 的 `kind`：

- `choice`：`options` 2–4 项。
- `judge`：`options` 恰好 2 项。
- `blank`：只有 `prompt`，不要 `options`。

`options` 的每一项含 `id` 与 `text`，同一张卡里 `id` 不重复。参数里不得出现正确答案或对错标记；出现、缺字段、项数不对、或还不是完整 JSON，这张卡都不合法，不升起。不合法时把失败原因送回模型，这一截仍算一截。

`end_class` 成功只表示模型请求收课。程序在当前这一问结束后收课，并立刻在同一页开下一节。它不能代替给学生看的那句话。

## 流式和卡片

SSE 要解析工具调用的增量，不能只解析正文。`finish_reason=tool_calls` 表示这一截是工具。工具参数在拼成完整 JSON 之前，不出卡片，也不按半截参数执行写入。

卡片用底部半屏。选择和判断先点中一项再确认，确认前可以改选。填空在卡片里写下内容再确认，确认前可以改。卡片打开时盖住输入框。卡片上另有「不会」，点它不选任何一项。

有当前这一句时，上课页可以分别遮住它的中文或英文。遮住只影响这一句在屏幕上的显示，不改已经写在气泡里的字，也不代替判分。

确认后的用户消息由程序抄入：选中的选项文字，或填空写下的文字。然后按新的一问开始。

## 课的边界

切课只为控制费用，不是教学单元。没有空白的「新对话」，也没有让学生自己开一个空线程的入口。

满足下面任一条就收当前节，并立刻在同一页开下一节。新的一节用上面那条不显示的提示让模型先说话。屏幕从这一节自己的消息画起。上一节留在本机，可以再查阅，但不进入新的一节，也不发给模型。

- 距上一条消息超过 2 小时，再打开上课页就开新课。超过 2 小时才收课时，未确认卡片作废，不记作答。
- 学生点「先到这」：立即收课。未确认卡片作废，不记作答。
- 本节成功的 `record_attempt` 达到 6 次，或学生用户消息达到 12 条，以先到者为准。学生消息包括打出的字、卡片确认和「不会」，不包括那条不显示的开场提示。次数到达后不打断正在进行的工具循环；当前这一问结束后再收课。若这一问停在未确认卡片上，先等学生确认，并让模型对这次确认说完，再收课。
- 过午夜但距上一条不到 2 小时：不切。

`end_class` 的收课时机与次数封顶相同：当前这一问结束之后，同一页开下一节。

## 存储

SQLite 使用 `english_coach.db`，schema 升到 3。升级时保留现有各表和数据，只新增上课用的表。旧的每日五词相关表留下，但不再作为上课主路径，也不把它们的进度换算成新的学习项。

新表：

- `study_items`：学习项。`prompt_cn`、`target_en`、`difficulty`（1–5）、`reason`、`status`（没练过 / 不稳 / 会用）、`due_at`。
- `study_attempts`：作答。指向哪一条学习项、对错、错误类型、`corrected_en`、`revealed`、程序抄入的原文。
- `study_classes`：一节课。收课时写入三行收课条。
- `study_class_messages`：本节消息。卡片只存题面和确认文字两条普通消息。开场提示不入库、不显示、不计学生消息。不存工具 JSON。
- `study_class_checkpoints`：本节投影检查点（`untilMessageId` 与正文）。只服务本节，下一节不读。

学生事实放在 `settings`：`learner_name`、`learner_job`、`learner_goal`。当前题目是 `learner_current_item`。成功的 `note_fact` 更新名字、工作和目标。

词页只供查阅词书。查阅不写作成绩，也不决定一条学习项是不是「会用」。
