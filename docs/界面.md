# 界面

日期：2026-09-30。本文描述已经装上手机的表单版。下一版的启动、底栏、每日闭环、记录和设置以 [产品交互.md](产品交互.md) 为准。学习规则仍以 [能力设计.md](能力设计.md) 为准。按那份文档改代码之前，手机上的界面仍是本文。屏幕上的名称用「今日英语」。

一个人在工位上打开，一只手能点完。一屏只做一件事。界面文字用中文，要练的词和句子用英文。

## 整体

底部四项：今天、词、记录、设置。练习不放在底部，从「今天」推进去，占满屏幕。左上角关闭回到「今天」，进度已经记下。系统返回键同样只离开，不丢进度。

颜色保持浅底深字。主按钮只用一种深绿色。答对用同一绿色的短字，答错用暗红色的短字，不用动画挡在下一题前面。连续天数是「今天」顶部的一个数字，打卡时不放烟花，不要求分享。

答题框关闭自动更正和联想，避免手机把答案填进去。英文答题用英文键盘。

## 第一次打开

只有 DeepSeek 密钥还没填时，进设置，不进今天。

这一页从上到下是：

1. DeepSeek 密钥。地址和模型名收在「高级」里，默认 `https://api.deepseek.com` 和 `deepseek-flash`。
2. 「测试连接」。成功后主按钮变成「开始今天」。
3. 参考翻译密钥，默认折起。展开后填写 TokenHub 密钥，地址和模型名同样收在高级里，默认 `https://tokenhub.tencentmaas.com/v1` 和 `hy-mt2-plus`。不填也能开始。

不在第一次打开时询问称呼、水平、目标、语气和每天词数。这些用默认值：简洁语气、能应付简单工作对话、目标职场、每天 5 个新词。人在设置里改，改动从下一天的计划生效。今天已经生成的计划不动，设置页用一行字说明。

## 今天

打开就是这一页。

顶部一行：日期，连续天数，三枚打卡状态。三枚分别是认词、对话、考核。完成的实心，未完成的空心。三枚都实心时，这一天显示「已完成」。

中间一个主按钮，文案按当前进度变：

| 状态 | 按钮 |
|---|---|
| 还没认词 | 开始认词 |
| 认词未做完 | 继续认词 |
| 认词已够，对话未完，场景未写 | 开始对话 |
| 场景正在写 | 场景写好后继续，按钮显示进行中，可以离开 |
| 对话未完 | 继续对话 |
| 对话已完，考核未完 | 开始考核 |
| 三条都完成 | 看今天的笔记 |

主按钮下面先放 2 张词卡：英文、中文、词性。其余新词和待复习词在「其余 n 个」里展开，不占第一屏。有到期错词时，主按钮下方多一行「错词 2」，点进去做，没有就不显示。

不在首页放聊天记录，不放教案正文。

## 认词

一屏一词。上半屏是中文释义和词性，下半屏是输入框和「提交」。

提交后输入框留下，框下出现结果：

- 答对：绿色「对了」，按钮变成「下一个」。
- 答错：暗红色给出正确英文，按钮变成「先记住，下一个」。这一词进入错词队列。

做完当天名单后回到「今天」，不自动跳进对话。用户自己点主按钮。比对忽略大小写和首尾空格。

## 对话

进入时如果场景还没有，这一屏只有场景名的位置和一句「正在写今天的场景」，以及关闭。写完或失败后再出现内容。失败时同一位置放原因和「重试」。

场景写好后，屏幕从上到下：

- 场景的中文名，英文名在下一行小字。
- 已经说过的句子收成小字，最多露出最近两句。
- 当前要接的那句用大字。对方的句子上面有「参考译文」。没填翻译密钥时，这个按钮不出现，场景自带的中文仍在句子下面。
- 轮到自己时，底部是输入框和「发送」。

发送后不把批改混进聊天气泡。底部升起一块半屏：至多两处问题，下面一句改对的英文，然后「下一句」。网络失败时半屏只写失败原因和「重试」，这一句不算说完。

最后一句走完，半屏换成「对话完成」和「去考核」。语法不插在句子中间。考核之前，场景标题旁有「这个语法」，点开是一张本地卡片：中文说明、两个例句、一个「再讲讲」。再讲讲调用讲解，结果写在卡片下面。

## 考核

一屏一题，顶部写「1 / 4」。题目、输入框、提交，布局和认词相同。批改仍用那块半屏。

四题按能力设计里的顺序。第 3 题需要场景却还没有时，这一屏只有「先生成场景」。四题都有结果后，半屏写通过了几题。少于 3 题时按钮是「重做没过的」和「先回到今天」。不少于 3 题时按钮是「回到今天」。

左上角始终可以离开。离开不宣布打卡。

## 错词

从「今天」的那一行进入，一屏一条，最多 3 条。有当时的错句时，上半屏显示那句和其中的问题，下半屏请用户重写整句。没有错句时，布局退回到认词。提交后用同一块半屏给结果，日期规则在半屏底部用一行字写出来，例如「明天再出现」或「3 天后再出现」。

## 打卡之后的笔记

三条打卡条件刚刚同时满足时，「今天」的主按钮变成「看今天的笔记」，并自动打开一次半屏。里面最多 5 条，每条是「错法 → 改对的句子 → 一句中文原因」，每条可以去掉。底部是「保存」和「跳过」。跳过或关掉之后，打卡仍然成立，主按钮恢复成「已完成」。已经跳过的当天不再自动弹出。

## 词

一张可滚动的列表：先是今天的词，再是以后会学的种子词和手动词。点一行进入词卡：英文、中文、词性、下一次什么时候出现。词卡上可以点「参考译文」来翻译例句，没有例句就不显示。

列表顶部有「添加」。三个字段：英文、中文、词性。保存后停在这张新词卡上，并写明「从明天开始练」。当天计划已经冻住，这里不能把它插进今天。

## 记录

按日期倒序。一行是日期、场景中文名、完成或未完成。点进去只读：新词、场景、保存过的笔记。不能在这里改日期或删错词。

## 设置

密钥和测试连接放在最上面。下面是四项分段选择，每项只有短标签：

- 每天新词：5、10、15、20
- 水平：简单工作对话、日常交流、更长的表达
- 目标：职场、日常、考试、都要
- 语气：简洁、朋友、老师

考试和「都要」只影响场景生成时的提示，不增加新的题型。第一版题型始终是词加短对话。

页底一行小字：学习记录只在这台手机上，卸载即删除。

## 断网

能点的按钮保持可点。认词、词卡、记录、已写好的对话回看都可用。要联网的动作失败后，把原因写在按钮下面，不用整页错误。已经记下来的对错不回滚。
