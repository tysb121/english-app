# 能力设计

日期：2026-09-30。本文是要实现的能力合同。与 [产品方向-2026-09-30.md](产品方向-2026-09-30.md) 冲突时，**以方向文档为准**，并回写本文。屏幕结构见 [产品交互.md](产品交互.md)。

一句话：默认练习是 **CEFR 分级词 + 教练聊天主线（懂了 / 用过 / 轮次）**。手机直接调用两家厂商，不经过自建服务器。DeepSeek 负责场景、批改和讲解；腾讯云 TokenHub 只负责整句参考译文。模型请求的验收在安卓手机上完成。

## 已定接口

依据 [Chat Completions](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion)、[模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing) 和 [错误码](https://api-docs.deepseek.com/zh-cn/quick_start/error_codes)（2026-09-30 查阅）。

| 项 | 取值 |
|---|---|
| 方法 | `POST https://api.deepseek.com/chat/completions` |
| 鉴权 | `Authorization: Bearer <用户密钥>` |
| 默认模型 | `deepseek-flash` |
| 兼容地址 | 允许改成 `https://api.deepseek.com/v1`，`v1` 不表示模型版本 |
| 结构化任务 | `stream: false`，`response_format: { "type": "json_object" }` |
| 思考 | 结构化任务关闭思考；自由聊天可按设置开启 thinking 流式 |
| 温度 | 只传 `temperature`，不传 `top_p`。场景生成 0.4，评分和讲解为 0 |
| 工具 | 不使用 tools / tool_choice |

默认模型用 Flash。设置里保留模型名文本框，默认 `deepseek-flash`。JSON 模式只保证正文是合法 JSON；提示词须写明「只输出一个 JSON 对象」。`finish_reason` 非 `stop` 时整次作废，不写入进度。

单次超时 60 秒。价格按官方页执行，应用不内置价目。余额用尽返回 402，提示去 DeepSeek 充值。

## DeepSeek 只做这些事

场景、批改和讲解走 DeepSeek。系统提示词规定：你是简短的英语教练；对话和例句用英文；讲解用中文；一次只指出至多两处问题，并给出改对后的整句；结构化任务只输出要求的 JSON。语气来自设置（默认简洁）。`user_id` 使用本机安装时生成的随机 ID。整句参考翻译不走这个客户端。

本地在写入进度前校验 JSON。缺字段、类型不对、或数组长度不合约束，都算失败。失败时自动再请求一次；第二次仍失败就停在当前题。两次失败都不改复习日期，也不算答错。

| 调用 | 何时 | max_tokens | 成功后写入 |
|---|---|---|---|
| `fill_scene` | 当天计划已冻住，场景尚空，且进入短对话需要场景 | 1200 | 当天场景，只写一次 |
| `grade_open` | 用户提交造句或短对话回复 | 400 | 通过与否、至多两条纠错；造句时写入该词的造句结果 |
| `explain` | 用户在语法卡片或纠错上追问 | 500 | 不写进度；可收进当天笔记草稿 |

`fill_scene` 返回：`scenario_en` / `scenario_cn`、`phrases`（1–5）、`dialogue`（6–10 句，`speaker` 仅 `A`/`B`）、`grammar`（含正好 2 条 `examples`）。每个当天新词至少在对话英文里出现一次。不符合则重试，仍不符合则场景保持未生成。

`grade_open` 返回：`pass`、`errors`（0–2）、`corrected_en`。本地收紧：`errors` 为空则 `pass` 视为 true。应用不把模型返回的日期、掌握度或打卡结论写入进度。

`explain` 返回 `{ "answer_cn": "", "example_en": "" }`。

场景 JSON 里的中文由 DeepSeek 与英文成对生成，不再交给腾讯云重译。

## 屏幕与能力

### 1. 连接

第一次打开：先选水平，再填 DeepSeek 密钥（也可「先看看」进壳）。密钥写入 `flutter_secure_storage`，不进进度库、不进日志、不进安装包。没填翻译密钥时参考译文不可用，其余练习照常。

「测试连接」发最短 JSON 探测。结果按 HTTP 状态说明（200 已连通 / 401 密钥无效 / 402 余额不足 / …）。密钥可稍后更换；不删除学习记录，不重抽已冻住的当天计划。

### 2. 今天与选词

首页是当天计划。练习进入同一条教练线程。

本地在当天第一次打开时生成计划并**冻住**（断网也可）：

- **新词**：默认 5 个，可改为 10 / 15 / 20。先取尚未进入过任何一天的**用户手动词**；名额不够再从**当前 CEFR 水平、尚未当过新词**的 `cefr_core` 池中**随机**抽取。抽过的记入本地，下次当新词跳过。
- **到期复习**：未进错词队列、复习日不晚于今天的词。
- **错词**：到期且未解决的，最多 3 条。

水平展示名：**入门 / 基础 / 进阶**（对应 CEFR-J A1 / A2 / B1）。改水平或每天词数都从**明天**生效；今天计划不动。职场短句种子已删除，无加餐入口。

首页显示：主按钮、三枚状态（认词 / 造句 / 对话）、新词预览（未认只显示中文）、错词入口（有则显示）、场景状态。本级未教新词库存为 0（`untaught == 0`）时，提示是否升到下一档（见下）。

### 3. 认词

完全离线。一次一词：展示英文、中文释义、词性（中文标签）。主按钮「认识了」前进。不输入、不比对、无正确率门槛。点过即记为已看；不进错词队列；并推进第 2 / 4 / 8 天复习。当天计划新词全部点过即认词完成。不调用模型。

中→英默写/听写不在每日路径内；错词练习若仍保留输入比对，属对话后的可选路径，不参与打卡。

### 4. 造句

认词完成后进入。文案提示「写一句就能进下一步」；可点今天词填入，并给弱起头提示。每个当天新词至少造一句英文，提交给 `grade_open`。结果写入该词的造句记录（有记录即算做完，不论 pass）。不提供跳过按钮；写一句即前进。需网络。

### 5. 短对话

造句做完后进入。若场景尚空则调用一次 `fill_scene` 并保存，同一天不重生成。对方一句、用户一句；首轮可有句子槽或 2–3 个可选开口。用户话交给 `grade_open`。走完对话记为完成。语法卡片可选，不挡对话。需网络。

**取消**单独的四题考核。旧进度里若残留 `quiz` 字段，读入时忽略且不再写入；不作为打卡条件。

### 6. 错词

独立练习，最多 3 条，没有则首页不显示入口。优先用记下的错句；没有则退回认词式。间隔：

| 当前轮 | 答对 | 答错 |
|---|---|---|
| 首次（明天） | 下次 3 天后 | 仍明天 |
| 第二次（3 天） | 下次 7 天后 | 退回明天 |
| 第三次（7 天） | 移出队列 | 退回明天 |

错词不单独决定打卡；通常排在短对话之后。

### 7. 打卡与笔记

打卡由本地计算，模型不能宣布。三条同时成立：

1. **懂了**：每个当天新词都点过词卡「懂了」（无正确率门槛；等同旧认词）。
2. **用过**：每个新词至少一次——用户消息命中该词，或点词 chip 填入输入框（账本复用原造句结果字段）。
3. **轮次**：教练聊天用户↔教练回合达到本地上限（默认 6；账本复用原对话游标 / dialogueDone）。

待复习与错词不计入认词完成条件。打卡后可出最多 5 条笔记草稿（错法 → 改对 → 中文原因）；确认才保存，跳过仍算完成。打卡后若本地有明天到期的复习/错词，今天页一行预告。

### 8. 水平升级提示

**不自动跳级**，模型也不改水平。

当本级「还未当过新词」的库存为 **0**（全部教过）且存在下一档时，在「今天」或「我的」提示是否升到下一档。用户确认后立刻写入新水平，**从明天**按新级抽词；今天计划不动。用户可「暂不」关掉提示。也可在「我的」随时手动改水平（同样明天生效）。升级后未掌握词与错词仍按复习回来。

### 9. 加词与词表

默认主词书：`assets/wordbooks/cefr_core.json`（CEFR-J + ECDICT 中文），见 [词书-cefr.md](词书-cefr.md)。用户可添加英文 / 中文 / 词性；新手动词优先进入以后新词名额。当天计划已冻住则从下一天起算。

考试向词书可作加餐（本轮未做入口）。职场短句种子已删除。

### 10. 整句参考翻译

对话或笔记里点「参考译文」时走 TokenHub Hy-MT2，不走 DeepSeek，不参与判分。

| 项 | 取值 |
|---|---|
| 方法 | `POST https://tokenhub.tencentmaas.com/v1/chat/completions` |
| 鉴权 | `Authorization: Bearer <TokenHub API Key>` |
| 模型 | `hy-mt2-plus`（可改 lite / pro） |
| 输出 | 普通文本，非 JSON |

失败保留原文并说明原因。传统 `TextTranslate` 不接入。

### 11. 记录与续练

按日期列出计划：新词、是否打卡、场景名、笔记。只读。

每个步骤保存位置：认词游标、造句已完成词、对话句序、错词游标。中途退出再打开停在未完成步骤；已判定的不重判。场景已保存则不再调用 `fill_scene`。完成后主按钮为「回看今天」。

## 本地数据

| 数据 | 存哪 |
|---|---|
| 词书（cefr_core） | SQLite `wordbook`（首启从 assets 灌入）；启动时仍加载到 LessonStore 内存供查词 / 抽词 |
| 计划、答题、错词、复习、打卡、聊天 | SQLite（`english_coach.db`）；旧 JSON 仅一次性迁移 |
| DeepSeek / TokenHub 密钥 | `flutter_secure_storage`（**始终不进业务库**） |

进度事实包括：安装 ID、设置（水平、每天词数、升级提示是否已关等）、每天计划与游标、造句结果、场景、答题事件、错词队列、复习日、笔记、模型调用摘要（任务名 / 成败 / finish_reason / tokens，不含提示词全文）、教练线程消息与检查点。

复习日只由答题事件计算。删除应用即删除这些数据；第一版不做导出和云同步。

## 离线时还能做什么

可以：看今天的词、做认词、回看已生成对话（无需重评）、看错词题面、看笔记和记录。

不可以：生成场景、造句/对话批改、讲解、参考译文、测试连接。已写入的进度不因断网回滚。

## 不设后端

手机作为 HTTPS 客户端访问厂商公网接口。不部署自有服务器。安装包只声明 `INTERNET`。设置拒绝非 `https` 地址。无云同步；学习记录只在本机。

## 验收路径

1. 选水平、填 DeepSeek 密钥（或先看看），测试连接可通。
2. 断网仍能生成当天计划并点完认词。
3. 联网走完造句与短对话；中途杀进程可续。
4. 非法 JSON 批改不改复习日。
5. 故意答错 → 次日错词；答对新词 → 第 2 天复习。
6. 三条件满足后打卡；笔记仅确认后保存。
7. 本级未教新词耗尽时出现升级提示；确认后次日按新级抽词，今天不动。
8. 手动加词出现在下一天新词里。
9. 401 / 402 / 无网络时认词仍可用。

## 本轮不做

语音和发音、端侧翻译、iOS、自建后端、账号云同步、单独四题考核、职场短句种子、让模型自动改水平、把密钥写入 SQLite。
