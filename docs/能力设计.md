# 第一版能力设计

日期：2026-09-30。本文是第一版要实现的能力合同。规则与 [目标.md](目标.md) 冲突时，以本文为准，并回写目标文档。

第一版由手机直接调用两家厂商，不经过自建服务器。DeepSeek 负责场景、批改和讲解。腾讯云机器翻译只负责整句参考译文。模型请求的验收在安装到安卓手机之后完成。浏览器跨域会挡住这些接口，所以不把 Chrome 调通接口当作目标。Chrome 只在需要时看布局。

## 已定接口

依据 [Chat Completions](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion)、[模型与价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing) 和 [错误码](https://api-docs.deepseek.com/zh-cn/quick_start/error_codes)（2026-09-30 查阅）。

| 项 | 第一版取值 |
|---|---|
| 方法 | `POST https://api.deepseek.com/chat/completions` |
| 鉴权 | `Authorization: Bearer <用户密钥>` |
| 默认模型 | `deepseek-flash`（当前为 DeepSeek-V4.1-Flash） |
| 兼容地址 | 允许改成 `https://api.deepseek.com/v1`，`v1` 不表示模型版本 |
| 输出 | `stream: false`，`response_format: { "type": "json_object" }` |
| 思考 | `thinking: { "type": "disabled" }`，`reasoning_effort: "none"` |
| 温度 | 只传 `temperature`，不传 `top_p`。场景生成 0.4，评分和讲解为 0 |
| 工具 | 不使用 tools / tool_choice |

默认模型用 Flash，不用即将有序下线的 `deepseek-v4-pro`。设置里保留一个模型名文本框，默认 `deepseek-flash`，避免模型改名后必须发版。旧名 `deepseek-chat`、`deepseek-reasoner` 不作为预设。

关闭思考模式有三个原因：结构化 JSON 不需要思维链；非思考模式才接受我们设置的 `temperature`；输出按 token 计费，短练习不应为推理 token 付费。非思考模式未设置 `max_tokens` 时默认输出上限是 8K，第一版仍显式设置更小的上限，便于把截断当成失败。

JSON 模式只保证正文是合法 JSON。提示词里必须写明「只输出一个 JSON 对象」。`finish_reason` 为 `length`、`content_filter`、`insufficient_system_resource` 或 `aborted` 时，整次调用作废，不写入进度。

非流式请求在排队时可能先收到空行保活。客户端等待完整 JSON 正文，空行不视为结束。单次超时 60 秒。个人使用的并发远低于账号限制（Flash 2500），不为限速做队列。

价格按官方页执行，应用不内置价目。2026-09-30 的 Flash 高峰价约为输入未命中 2 元/百万 token、输出 8 元/百万 token，空闲时段减半。一次场景生成加几次短评分，对个人练习是小额消耗。余额用尽时接口返回 402，应用只提示去 DeepSeek 充值。

## DeepSeek 只做三件事

场景、批改和讲解走同一个 DeepSeek 客户端。系统提示词规定：你是简短的英语教练；对话和例句用英文；讲解用中文；一次只指出至多两处问题，并给出改对后的整句；只输出要求的 JSON，不要 Markdown 围栏。语气来自设置（默认简洁）。`user_id` 使用本机安装时生成的随机 ID，只含字母、数字、下划线和连字符，不放姓名或密钥。整句参考翻译不走这个客户端。

本地在写入进度前校验 JSON。缺字段、类型不对、或数组长度不合约束，都算失败。失败时自动再请求一次，把上一次原文附在用户消息里，要求只重发合法 JSON。第二次仍失败就停在当前题，界面给出重试。两次失败都不改复习日期，也不算答错。

| 调用 | 何时 | max_tokens | 成功后写入 |
|---|---|---|---|
| `fill_scene` | 当天计划已冻住，场景尚空，且用户打开对话或依赖场景的题目 | 1200 | 当天场景，只写一次 |
| `grade_open` | 用户提交造句、翻译、情景反应、自由表达 | 400 | 这一题的通过与否、至多两条纠错 |
| `explain` | 用户在语法卡片或纠错上追问 | 500 | 不写进度；可收进当天笔记草稿 |

`fill_scene` 的用户消息包含：当天新词（英文、中文、词性）、学习目标、水平、已有本地场景提纲（可为空）。模型返回：

```json
{
  "scenario_en": "Morning standup",
  "scenario_cn": "早会",
  "phrases": [{ "en": "Let's start the standup.", "cn": "我们开始站会。" }],
  "dialogue": [{ "speaker": "A", "en": "What did you finish yesterday?", "cn": "你昨天做完了什么？" }],
  "grammar": {
    "title_en": "Simple past",
    "title_cn": "一般过去时",
    "point_cn": "说已经发生的事，规则动词常加 -ed。",
    "examples": ["I finished the report.", "I sent the notes."]
  }
}
```

约束：`phrases` 1 至 5 条；`dialogue` 6 至 10 句，`speaker` 只能是 `A` 或 `B`，`B` 是用户；每个当天新词至少在对话英文里出现一次；`examples` 正好 2 句。不符合就走上面的重试，仍不符合则场景保持未生成。

`grade_open` 的用户消息包含：题目、参考答案或必用词、用户原文。模型返回：

```json
{
  "pass": true,
  "errors": [{ "excerpt": "He go", "fix": "He goes", "why_cn": "第三人称单数要加 s。" }],
  "corrected_en": "He goes to the standup at nine."
}
```

`errors` 长度 0 至 2。本地再收紧一条：`errors` 为空则把 `pass` 视为 true；`errors` 有内容时采用模型给出的 `pass`。应用不把模型返回的日期、掌握度或打卡结论写入数据库。

`explain` 返回 `{ "answer_cn": "", "example_en": "" }`。若本地有对应语法卡片，卡片正文放进用户消息，模型顺着卡片讲，不另编课程。

场景 JSON 里的 `scenario_cn`、短语和对话的 `cn` 由 DeepSeek 在 `fill_scene` 里一并写好。这些中文要和它刚写的英文成对，不再交给腾讯云重译。

## 屏幕与能力

### 1. 连接

第一次打开没有 DeepSeek 密钥时，只进入设置页。DeepSeek 字段为：Base URL（默认 `https://api.deepseek.com`）、API Key、模型名（默认 `deepseek-flash`）。参考翻译字段为：TokenHub Base URL（默认 `https://tokenhub.tencentmaas.com/v1`）、API Key、模型名（默认 `hy-mt2-plus`）。两处地址都只接受 `https`。两把密钥都写入 Android Keystore（`flutter_secure_storage`），不进进度库，不进日志，也不写进安装包。机器翻译旧接口的 SecretId、SecretKey 不能用来调用 TokenHub。没填翻译密钥时，参考翻译按钮不可用，其余练习照常。

「测试连接」发送一条最短请求：模型为当前模型名，`max_tokens` 16，`response_format` JSON，用户消息要求返回 `{"ok":true}`。结果按 HTTP 状态说明：

| 状态 | 界面 |
|---|---|
| 200 且 JSON 可解析 | 已连通 |
| 401 | 密钥无效 |
| 402 | 余额不足 |
| 400 / 422 | 地址或模型名不被接受 |
| 429 | 稍后再试 |
| 500 / 503 / 超时 / 无网络 | 服务暂时不可用，认词仍可使用 |

密钥可稍后在设置里更换。更换不删除学习记录，也不重抽已经冻住的当天计划。

### 2. 今天

首页是当天计划，不是聊天。

本地在当天第一次打开时生成计划并冻住，断网也可以生成。计划包含三份名单：

- **新词**：默认 5 个，可改为 10、15、20。先取尚未进入过任何一天的手动词，名额不够再按种子词表的固定顺序取。当天不再重抽。
- **到期待复习的词**：没进过错词队列、复习日不晚于今天的词。
- **错词**：到期且未解决的，最多 3 条。

首页显示：继续上次停下的片段、新词（先露出 2 个，其余可展开）、待复习、错词、场景状态（未生成 / 生成中 / 已生成）、打卡进度三条。

### 3. 认词

完全离线。先练首页露出的 2 个新词，再练其余新词和待复习词。题面是中文释义，用户输入英文。比对时忽略大小写和首尾空格。答错进入错词队列。答对且该词不在错词队列中，则推进第 2、4、8 天的复习。看英文回忆中文放在词卡里，不单独出题。

这一步不调用模型。词表里的中文就是翻译。界面见 [界面.md](界面.md)。

### 4. 场景与对话

用户打开对话时，若场景还没有，就调用一次 `fill_scene` 并保存。同一天不重新生成。生成期间可以离开，回来看到结果或失败后的重试。

对话按句进行。`A` 的句子由应用显示，轮到 `B` 时用户输入。逐句把用户的话交给 `grade_open`，必用条件是意思接得上这一句，并在这一天的后半段尽量用到尚未用过的新词。每句只展示至多两处纠错和一句改对的英文。进度记到第几句。走完最后一句，对话片段记为完成。

语法点显示在对话后面。点进去是本地卡片加一次可选的 `explain`。语法不挡在对话前面。

### 5. 考核

固定 4 题，一次一题。第一版只有一种题组：

1. 用今天的一条短语造句（`grade_open`）
2. 句子翻译（`grade_open`；若场景已生成，句子来自对话，否则用来自词表的短句，本地也能出题面，评分仍要模型）
3. 情景反应：给出 `A` 的一句，用户用英文接（`grade_open`，需要场景）
4. 自由表达：用至少 2 个今天的新词说两句（`grade_open`）

第 3 题在场景未生成时按钮为「先生成场景」。4 题全部有结果后，通过数不少于 3 则考核片段完成。未通过则当天不打卡，题目保留，用户可以重做未通过的题。用户明确结束时，当天保持未打卡，不自动宣布通过。

### 6. 错词

独立片段，最多 3 条，没有则首页不显示入口。题目优先用当时记下的错句重做；没有错句时退回认词。结果只通过本地间隔规则写入：

| 当前轮 | 答对 | 答错 |
|---|---|---|
| 首次，间隔到明天 | 下次改为 3 天后 | 仍是明天 |
| 第二次，间隔 3 天 | 下次改为 7 天后 | 退回明天 |
| 第三次，间隔 7 天 | 移出队列 | 退回明天 |

错词结果不改变考核是否通过，也不单独决定打卡。

### 7. 打卡与笔记

打卡由本地计算，模型不能宣布。三条同时成立：

- 每个当天新词都至少做对过一次认词。5 个词时，最后一次认词正确的不少于 4 个；其他词量按 80% 向上取整。
- 对话完成。
- 考核至少 3/4。

待复习词和错词不计入第一条。

打卡之后，应用用刚才的纠错起草最多 5 条笔记，格式固定为「错法 → 改对的句子 → 一句中文原因」。用户确认后才保存。拒绝或跳过则不写笔记，打卡仍然成立。

首页对已打卡的日期显示完成。连续天数由已打卡日期在本地算出。

### 8. 加词与词表

种子词约 70 条，由本项目编写，主题是上班间隙用得上的说法，够每天 5 个词用两周。不把 english-coach 的 `vocabulary.db` 放进仓库。

用户可添加英文、中文和词性。新手动词与种子词使用同一套计划和复习规则。添加后若当天计划已冻住，它从下一天开始进入新词名额。

### 9. 整句参考翻译

认词只用词表里的中文。考核里的翻译题仍由 DeepSeek 的 `grade_open` 批改，看的是意思和有没有用上当天的词。用户的译法和参考译文用词不同，只要批改通过，这一题仍然算过。

对话或笔记里对一整句点「参考译文」时，调用 TokenHub 上的 Hy-MT2，不调用 DeepSeek，也不调用即将收缩的机器翻译 `TextTranslate`。依据 TokenHub 的 [Hy-MT2 调用说明](https://cloud.tencent.com/document/product/1823/130078)（2026-09-30 查阅；大陆接入点见同一平台的地域地址）：

| 项 | 第一版取值 |
|---|---|
| 方法 | `POST https://tokenhub.tencentmaas.com/v1/chat/completions` |
| 鉴权 | `Authorization: Bearer <TokenHub API Key>` |
| 模型 | `hy-mt2-plus` |
| 消息 | 只有一条 user 消息。英译中时写「将以下文本翻译为中文，只输出译文，不要额外解释：」加上原文。中译英时把目标语言写成英文 |
| 输出 | 普通文本，不使用 JSON 模式，不使用工具 |

大陆站点用广州这一个地址，与[混元调用指南](https://cloud.tencent.com/document/product/1823/132252)里的示例一致。旧域名 `tokenhub.tencentcloudmaas.com` 在 2026-09-30 仍会应答，但文档示例已经改用 `tokenhub.tencentmaas.com`。国际站不作为默认。返回的正文去掉首尾空白后整段显示为参考译文。模型若多写了解释，这一次作废并自动重试一次；第二次仍不像一句译文，就停在按钮上让用户再试。译文不写入复习日期，也不当作标准答案去比对字符串。

失败时保留原文，并说明原因：没填密钥、401 密钥无效、402 未开通该模型或余额不足、无网络。词表释义和场景里已有的中文始终可看。

`hy-mt2-plus` 是 7B 的翻译模型，够一句对照。设置里可以改成更快的 `hy-mt2-lite`，或质量更高的 `hy-mt2-pro`。三个都只做参考翻译。

传统机器翻译 `TextTranslate` 不接入。官方安排是：2026-10-01 起不再向新用户开放、不再发放新的免费包，QPS 逐月下降；2027-10-01 起 QPS 降到 0，接口不可用。已开通的旧密钥在那之前仍可能能用，但那把 SecretId 不能调用 TokenHub，第一版不为它保留一条实现。

### 10. 记录

按日期列出计划：新词、是否打卡、场景名、已保存笔记。只读。不提供 85 项能力矩阵，不提供让模型修改记录的入口。

### 11. 续练

每个片段保存自己的位置：认词做到第几个、对话到第几句、考核到第几题、错词到第几条。进程被杀掉或用户返回首页后，从该位置继续。已完成的片段不再重抽题目。场景 JSON 已保存后，再次进入对话不再调用 `fill_scene`。

## 本地数据

两份数据分开。种子词打在应用里，只读。进度在手机上的 SQLite 数据库。

进度库记录这些事实：

- 设置以外的安装 ID。密钥不在这个库里。
- 每天一行计划：日期、词量、是否冻住、打卡时间。
- 计划中的词：是新词、复习词还是手动词，以及认词最后一次对错。
- 当天场景 JSON，以及对话、考核进行到哪里。
- 每一次答题事件：片段、题目、对错、用户原文、纠错 JSON。
- 错词队列：错句、正确句、轮次、下次日期、是否已移出。
- 普通词的下次复习日。
- 用户确认过的笔记。
- 每次模型调用的任务名、是否成功、`finish_reason`、token 用量。不保存提示词全文，避免密钥或长对话重复落盘。

复习日只由答题事件计算。删除应用就会删除这些数据，第一版不做导出和云同步。

## 离线时还能做什么

可以：看今天的词、做认词、做已经生成好的对话里不需要重新评分的回看、看错词题面、看笔记和记录。

不可以：生成场景、给开放题打分、追问讲解、参考译文、测试连接。对应按钮保留，失败原因写在按钮下方。已经答完并成功写入的进度不会因为后来断网而回滚。

## 不设后端

全程是手机作为 HTTPS 客户端，访问厂商的公网接口。不部署自己的服务器，也不申请自己的域名或证书。

跨域、Referer 和网站备案约束的是浏览器里的网页。安卓应用不发送网页来源，DeepSeek 和腾讯云也不要求调用方拥有某个域名。安装包只声明 `INTERNET` 权限，使用系统已经信任的证书访问 `https` 地址。不为这两家单独做域名白名单或证书锁定。设置里拒绝非 `https` 地址，避免密钥被发到明文网址。

个人使用会遇到的限制是这些：

- 两把密钥都在这台手机的 Keystore 里。换机或卸载后要重新填写。不把密钥打进安装包，因此不能把这个包公开分发后再替别人付费调用。
- TokenHub 或 DeepSeek 的密钥若绑定了固定 IP，手机网络的出口地址一变就会失败。个人使用不要绑 IP。
- DeepSeek 返回 401、402、429 或 5xx 时，只影响场景、批改和讲解。TokenHub 密钥无效、模型未开通或余额不足时，只影响参考译文。认词和已保存的内容两边都不依赖。
- 公司网络或私人 DNS 可能拦截 `api.deepseek.com` 或 `tokenhub.tencentmaas.com`。换一个能打开该网站的网络即可。不为了绕过拦截去加一台中转服务器。
- 没有自己的服务器，就没有云同步，也不能在服务端替手机隐藏密钥。学习记录只在这台手机上。

这些限制不改变第一版的结构。浏览器里调不通，是因为跨域，不是因为缺少自己的域名。

## 第一版验收

在用户自己的安卓手机上，用自己的 DeepSeek 密钥，走完下面的路径算第一版完成：

1. 填写 DeepSeek 密钥，测试连接返回已连通。填写 TokenHub 密钥后，一句英文能返回参考中文。
2. 断网仍能生成当天计划并做完认词。
3. 恢复网络后生成一次场景，逐句走完对话，中途杀掉应用还能续上。
4. 做完 4 道考核，开放题返回的非法 JSON 不会改动复习日。
5. 故意答错一个词，第二天它出现在错词里；答对一个新词，它出现在第 2 天的复习里。
6. 三条打卡条件满足后，日期记为完成；笔记只有确认后才保存。
7. 手动加一个词，它出现在下一天的新词里。
8. 401、402 和无网络时，认词仍可使用。

## 第一版不做

语音和发音记录、端侧 Hy-MT、iOS、自建后端、导入 14694 词、85 项能力矩阵、流式输出、思考模式、工具调用、图像输入、多模型自动切换、用 Chrome 证明模型调用成功。
