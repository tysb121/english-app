# Wordbook attribution / NOTICE

This directory ships open vocabulary data assembled for **今日英语**.

## CEFR-J (levels + English lemmas)

- **Dataset:** CEFR-J Vocabulary Profile (Wordlist) Version 1.5

- **Official download:** http://www.cefr-j.org/download.html

Only **A1 / A2 / B1** rows are shipped in `cefr_core.*`. B2+ rows are omitted for now.

## Chinese glosses

Primary gloss source:

- **ECDICT** — https://github.com/skywind3000/ECDICT  
  License: **MIT**  
  Short Chinese senses extracted from `translation` fields; POS-matched when possible.

Evaluated fallback (Apache-2.0; not required for the final match set after ECDICT):

- **LinXueyuanStdio/DictionaryData** — https://github.com/LinXueyuanStdio/DictionaryData  
  License: **Apache-2.0**  
  File: `word_translation.csv`

A small number of multi-word / orthography gaps were filled by hand and tagged `cn_source=curated` in `cefr_core.jsonl` (see build meta). Glosses were **not** mass-generated by an LLM.

## Rebuild

Vendor CSVs live under `tool/vendor/` (gitignored). Rebuild with:

```bash
python3 tool/build_cefr_core.py
```

## Not used as the default book

KyleBing / exam-pack style lists are intentionally **not** the default wordbook.
